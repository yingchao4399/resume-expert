# 职途智策 AgentTeam —— 面向求职决策的可信多 Agent 协作系统

## 作品简介（326 字）

求职者的真正难点不是“生成一份更好看的简历”，而是把零散经历转化为可验证事实，并针对不同岗位做出可信的准备、改写与交付决策。本项目面向求职者与求职辅导者，将「JD 原文 → 已确认岗位要求 → 已确认经历事实 → 匹配与缺口 → 简历与投递交付」组织为可追溯闭环。

核心方案：以 AgentTeams 为协同基点，主控按阶段路由四个职能 Agent——JobRequirementAnalyst 拆解带原文锚点的 JD 需求地图；EvidenceCurator 检索、筛选并维护候选事实；ResumeStrategist 仅基于已确认事实生成岗位定制优化方案与简历草稿；QualityDeliveryGuardian 执行 Schema、引用、过期状态、ATS 与导出门禁；以 requirementId、claimId、traceId 传递上下文，高风险写入与最终导出保留人工确认。

创新点：候选/确认/待复核三级可信状态、确定性岗位准备度评分、结构化模型校验与可回放 Trace，不做模型自报，区别于普通简历美化工具。

开放复用：核心能力沉淀为可复用 Skill、接口契约与合成评测集。

当前进展：已实现本地版本管理、事实库、四阶段工作流、155 项单测与合成评测；多 Agent 运行时为复赛路线。
