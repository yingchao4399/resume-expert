# 页面与交互信息架构建议

## 1. 双工作台结构

继续保留现有“简历助手 / 开发者工作台”切换，但简历助手内部逐步扩展为五个业务空间。

```text
简历助手
├─ 求职工作台
│  ├─ 材料
│  ├─ 分析
│  ├─ 制作
│  └─ 交付
├─ 职业资产
│  ├─ 项目与经历
│  ├─ 原子事实
│  ├─ 能力与标签
│  ├─ 数字证据
│  └─ 作品集素材
├─ 面试训练
├─ 投递复盘
└─ 公司研究

开发者工作台
├─ 工作流
├─ 运行追踪
├─ 测评中心
├─ 开发记录
└─ Flowise 实验
```

普通用户不需要理解 Trace、Flowise 或工作流草稿；高级开关只控制开发者工作台入口，不控制业务功能。

## 2. 材料页重构

### 2.1 目标岗位

建议字段：

- 岗位名称；
- 行业；
- 求职阶段；
- 目标公司名称；
- 团队/业务线；
- 公司类型：小微企业、民营企业、中型公司、大型企业/大厂、创业公司、外企、国企、央企、事业单位、政府/公共部门、社会组织、其他；
- 公司类型自定义；
- 公司规模；
- 公司阶段；
- 工作地点和工作方式；
- JD 原文。

公司类型默认值改为“未选择”，避免把中型公司当成用户事实。

### 2.2 能力偏好

拆成三个区域：

1. 岗位明确要求的能力：来自 JD 原文；
2. AI 推荐突出能力：显示理由、证据覆盖和采用按钮；
3. 用户希望突出能力：表达个人偏好，不能直接贡献 ATS 分。

### 2.3 补充信息

空白文本框上方提供方向按钮：

- 我有哪些项目但不会描述；
- 我有成果但不知道数字怎么写；
- 我想说明转行/空窗/职业方向；
- 我有作品、证书或链接；
- 我有岗位或公司的额外信息；
- 帮我检查还缺什么。

点击后生成回答框架或定向问题，不直接代写事实。

## 3. 职业资产工作台

### 3.1 项目列表

卡片展示项目类型、时间、状态、能力、证据完整度、适配岗位数和最近更新。支持：

- 新增、复制、删除、归档；
- 拖拽排序；
- 按能力、时间、类型、证据状态筛选；
- 从简历导入候选项目；
- 从 Flowise/Skill 访谈创建候选项目。

### 3.2 项目详情

不要一次展示几十个空输入框。使用分段访谈与完成度：

1. 背景和问题；
2. 目标、用户和约束；
3. 角色边界和协作；
4. 决策与行动；
5. 结果、数字和证据；
6. 失败、权衡和复盘；
7. 能力与话术。

每一段允许“我不知道怎么回答”，提供回忆提示和示例；示例明确标为虚构。

### 3.3 能力页

每个能力显示：

- 规范名称和别名；
- 分类；
- 用户自评等级；
- 证据校验等级；
- 支持项目和事实；
- 最近使用时间；
- 目标岗位要求等级；
- 能力缺口与下一项可补证据。

统计包括能力项目数、强证据数、近期使用、岗位覆盖和话术完整度，不输出“录用概率”。

## 4. JD 分析页重构

左侧显示带高亮锚点的 JD 原文，右侧按 Requirement 卡片逐条展示：

- 必须/优先/职责/背景；
- 原文；
- 业务含义；
- 可能的实际工作；
- 所需能力和行业经验；
- 已匹配项目与证据；
- 缺口；
- 面试如何体现；
- 可能追问；
- 反向提问；
- 推断依据和置信度。

用户可以纠正拆分、合并要求、调整权重和拒绝推断。

## 5. 补证页重构

每个问题卡显示“为什么问”“支持哪条 JD 要求”“当前缺什么”。操作：

- 回答；
- 给我回忆线索；
- 给我回答框架；
- 生成虚构示例；
- 暂时不知道；
- 选择另一个项目回答。

回答后先抽取原子事实和数字候选，用户逐项确认，再生成话术。追问停止原因对用户可见。

## 6. 面试训练

训练模式：

- 随机抽卡；
- 按 JD 要求；
- 按薄弱能力；
- 按项目深挖；
- 压力追问；
- 一句话 / 60 秒 / 3 分钟项目介绍。

每题流程：题目 → 用户文字/录音回答 → 自评 → 结构分析 → 证据检查 → 建议版本 → 差异对比 → 再答一次 → 保存修订。

## 7. AI 优化

从“选择四种固定风格并整体生成”改为：

- AI 推荐配置；
- 精炼程度；
- 技术/业务侧重；
- 风险克制程度；
- 关键词密度；
- 目标岗位语气；
- 自定义要求。

优化列表每项提供采用、拒绝、编辑、查看证据和恢复。实体、日期、数字变化时强制重新核对证据。

## 8. 教育背景

支持多段教育。每段可添加：学校、专业、学位、时间、GPA、排名、课程、荣誉、证书和描述。继续教育、训练营、职业证书使用独立类型。

系统根据岗位阶段建议显隐：校招突出课程/GPA/荣誉；资深社招通常精简；继续教育只有与岗位相关或解释转型时突出。

## 9. 投递复盘

在现有状态记录上增加：

- 阶段时间线和停留天数；
- 来源渠道；
- 未通过阶段和原因；
- 面试问题与对应 Requirement；
- 使用的简历/话术版本；
- 后续任务；
- 岗位族、公司类型、渠道和版本的分组统计。

界面必须提示样本量，不能把相关性描述成因果。

## 10. 公司研究

公司页分区：

- 基本身份与工商；
- 上市、融资与投资；
- 业务、产品、客户和行业位置；
- 招聘、岗位与薪酬；
- 知识产权、司法和劳动风险；
- 新闻、公众号、社媒、展会和成果；
- 公开评价样本；
- 研究覆盖、来源冲突和更新时间；
- 对当前 JD 的影响和反向提问。

主观评价必须显示来源类型和样本数量。HR、领导和员工的私人信息不提供画像按钮。
