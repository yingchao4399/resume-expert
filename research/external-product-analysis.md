# 商业产品与市场能力对照

> 研究模式：多产品深度对照
>
> 访问日期：2026-08-13
> 说明：本文件只记录公开页面可以支持的产品事实；“对简历专家的启示”属于本项目推论。

## 1. 市场不是一条完整链，而是三条彼此割裂的链

1. **简历与材料链**：Teal、Rezi、Kickresume、Huntr 解决简历制作、JD 定向优化、模板和部分面试准备。
2. **求职交易链**：LinkedIn、Indeed、BOSS 直聘解决职位发现、匹配、沟通和投递。
3. **公司信息链**：Glassdoor、脉脉、企查查、天眼查等提供主观评价、薪酬、工商、风险和公开企业资料。

它们普遍没有把“个人原子事实 → 项目/能力 → JD 要求 → 简历/面试/作品集 → 投递反馈”维护成可核验的长期依赖图。这正是简历专家最值得建立的差异化，而不是再增加一个通用 AI 改写按钮。

## 2. 商业简历与职业工作台

| 产品 | 已核验公开能力 | 可借鉴模式 | 不应照搬 |
|---|---|---|---|
| Teal | 简历构建、Job Tracker、AI 面试练习 | 把职位、简历版本、投递和练习放在同一工作台 | 将匹配提示或 AI 建议当成事实证明 |
| Rezi | JD 关键词定向、Rezi Score、分级付费 | 将问题拆成关键词、格式和内容等可执行项 | 为了补关键词而生成无证据经历，或把平台分数包装为真实 ATS 通过率 |
| Kickresume | AI 简历、模板、网站/求职材料 | 制作体验、模板预览、材料复用 | 以视觉模板数量代替证据质量和岗位匹配 |
| Huntr | Master Resume、岗位定向 Resume、Application Hub/Packet、逐项 AI review | “母版资产 → 岗位快照 → 投递包”最接近本项目目标 | 只保存最终文本，不保存它引用的原子事实与依赖 |

### 对简历专家的直接启示

- 采用 Huntr 式“职业资产母版 → 岗位版本 → 交付包”，但补上事实级引用、版本和失效传播。
- 保留 Teal 式投递/练习工作台，但把每次练习发现的新事实送回“候选确认区”，而不是直接改写资产库。
- 保留 Rezi 式可执行检查，但评分必须本地确定、显示公式、上限和误差，不称为真实 ATS 结果。
- 模板价值属于交付层；不能反过来决定底层事实模型。

## 3. 招聘、职业网络与公司体验

| 产品 | 已核验公开能力 | 本项目应吸收什么 |
|---|---|---|
| LinkedIn | Job Match、Job Tracker、职业档案与网络 | 岗位匹配理由、保存职位、阶段追踪；但不复制其社交网络范围 |
| Indeed | 职位和公司评价；官方职业建议强调结合多条评价判断 | 主观样本必须显示日期、数量、分歧和局限 |
| Glassdoor | 公司评价、薪酬、面试体验；有内容审核与虚假评价治理说明 | 将匿名体验明确标记为主观样本，不能当成公司事实 |
| BOSS 直聘 | 直接招聘沟通模式 | 将 JD 缺口转成用户可向招聘者核实的问题卡，而不是模型自行补全 |
| 脉脉 | 职场社区和招聘相关内容 | 可观察话题与体验信号，但不做私人画像或确定性团队判断 |
| 看准 | 已于 2024-09-30 停止服务 | 只作为历史案例，不列为当前可接入数据源 |

## 4. 企业公开信息平台

| 平台 | 公开能力 | 合理接入边界 |
|---|---|---|
| 企查查 | 企业查询、开放平台/专业数据产品 | 通过合法授权接口读取必要字段；每项事实保留来源、采集时间和许可边界 |
| 天眼查 | 开放平台 API 分类 | 同上；不抓取登录后页面，不绕过访问控制，不缓存超出许可范围的数据 |
| 国家企业信用信息公示系统 | 法定企业信用公示渠道 | 作为企业主体和部分登记/公示事实的重要来源，不替代司法、招聘和主观体验来源 |

### 公司研究的产品边界

- **事实**：工商、融资、官网公开信息、司法公开信息，均显示来源和采集日期。
- **公开信号**：招聘数量、新闻、会议、公众号内容，只用于形成待核验判断。
- **推断**：工作重心、团队痛点、业务阶段，必须显示依据、置信度和替代解释。
- **主观样本**：匿名评价、面试体验、社区讨论，不汇总成“公司一定如何”。
- **禁止**：无来源推断领导人格、HR 私人背景、个人喜好或内部关系。

## 5. 合规与数据边界

- 用户简历和职业事实属于高敏感个人材料；真实案例不得进入公开测评集、Git 或第三方分析服务的默认日志。
- 外部平台连接必须遵守平台条款，不使用通用爬虫规避技术措施。LinkedIn 明确提供[抓取条款](https://www.linkedin.com/legal/crawling-terms)，Glassdoor 也有[服务条款](https://www.glassdoor.com/about/terms-2020-07-08/)。
- 国内处理个人信息时应遵循[《个人信息保护法》](https://www.cac.gov.cn/2021-08/20/c_1631050028355286.htm)的数据最小化、目的明确和安全保障要求。
- 竞争与数据使用还需遵守[《反不正当竞争法》](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/fgs/art/2024/art_80019fe59e464196bef173dc56678a42.html)等适用规则；正式商用接入前应做专项法律审查。

## 6. 竞争定位

简历专家不应定位为“中文 Teal/Rezi”或“更多模板的 Kickresume”。更可防守的定位是：

> 一个本地优先、证据驱动的个人职业资产与求职决策工作台：它帮助用户把经历拆成可核验事实，映射到岗位要求，并在简历、面试、作品集和投递反馈中一致复用。

该定位同时解释了为什么下一步先修证据链和状态失效，而不是先做联网公司背调、通用 Agent 或更大的工作流画布。
