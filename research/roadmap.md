# 推荐版本路线图

## 总体原则

先修可信度，再重构个人职业资产，再扩展岗位匹配和训练闭环，最后建设公司公开情报。每个版本都应继续沿用“本地验证 → 推送 main → CI 全绿 → annotated tag”的发布方式。

## V1.7.3：可信度修复

目标：保证现有功能不会把过期、虚构或断链内容当成可信结果。

范围：

- JD、目标岗位、原始简历和关键公司输入变化时，让全部依赖分析失效；
- ATS 仅评估最终简历正文；
- Mock 不生成用户输入中不存在的人名、公司、时间和数字；
- 自动证据关联降级为候选，人工修改触发重新审核；
- 证据修改/删除触发依赖简历 stale；
- 修复备份合并外键、损坏恢复和重复候选；
- 按 JD 筛选发送给模型的证据；
- 同步 Prompt 和 Zod 条数约束；
- 修正四阶段与细步骤状态顺序。

发布门槛：代码审计列出的 P1 全部有回归测试，旧 V1.7.2 数据与备份可以无损迁移。

## V1.8.0：个人职业资产与原子证据

目标：把产品的事实来源从“简历大文本”迁移为可复用、可验证的职业资产。

范围：

- IndexedDB/Dexie 业务库与 Zod 连续迁移；
- 项目、工作经历、Demo 的 CRUD、排序、复制、归档和版本；
- `EvidenceClaim`、`MetricEvidence`、`EvidenceSource`、`RiskFinding`；
- 原子事实逐项确认；
- 数字的单位、基线、公式、样本、时间窗和来源；
- 真实依赖索引，事实变化自动使相关话术 stale；
- JSON 备份覆盖新领域对象，附件 Blob 单独管理。

本版本不引入 RAG，也不建设公司全量背调。

## V1.8.1：能力标签与熟练度

目标：将项目行为沉淀为可解释的能力档案。

范围：

- 规范标签、用户标签、岗位标签；
- 别名、分类、合并、拆分和自定义；
- 能力与项目、事实多对多绑定；
- 0–4 熟练度行为标尺；
- 用户自评与证据校验等级并列；
- 能力覆盖、最近使用、项目数量、证据质量和岗位族统计；
- 区分用户希望突出、岗位必须、系统推荐的能力。

## V1.8.2：JD 深度分析与定向访谈

目标：把 JD 从一组摘要升级为逐条可操作要求。

范围：

- 原文锚点、Requirement ID、must/preferred 和权重；
- 行为、产出、业务场景、行业经验和验证证据；
- 潜台词、团队痛点、工作重心、业务线、汇报关系等推断，带依据和置信度；
- 逐条项目匹配与可解释排序；
- 针对证据缺口的自适应提问；
- 回忆提示、回答框架、示例和稍后补充；
- 逐条面试准备和反向提问。

## V1.8.3：外部连接器与 MCP 可行性切片

目标：在不改变主流程、不扩大数据暴露的前提下，验证 MCP 是否确实降低公司公开资料接入成本。

范围：

- 先定义与协议无关的 `ExternalConnector`、`ConnectorPolicy`、`ConnectorResult` 和 `MCPSpan`；
- Direct/manual adapter 作为始终可用的基线和降级路径；
- 仅试验只读公司公开信息工具，默认 feature flag 关闭；
- 浏览器不持有凭证、不直连 MCP；Next.js 服务端负责 allowlist、Zod、超时、审计和确认门禁；
- 外部结果只进入候选研究快照，用户确认后才能成为业务数据；
- 覆盖未授权、拒绝、超时、Schema 错、恶意工具描述、网页提示注入、来源缺失和断网降级。

本版本不接通用浏览器、Shell、任意 SQL、全盘文件访问，也不把 Flowise 包装成 MCP。

## V1.9.0：多渠道话术、面试训练与教育扩展

目标：从同一组事实生成并维护一致的求职表达。

范围：

- `NarrativeAsset`：简历 bullet、一句话项目、60 秒故事、深挖版本和作品集章节；
- 优化建议逐条采用、拒绝和人工编辑；
- 可组合优化参数、自定义风格和带理由的 AI 推荐；
- 面试抽卡、用户回答、评分、对照、修订和证据回写；
- 多段教育、课程、GPA、荣誉、证书、继续教育和条件显隐；
- 作品集素材和附件沉淀。

## V1.9.1：投递反馈闭环

目标：用真实投递过程帮助用户发现材料与岗位策略问题，但不宣称因果。

范围：

- 阶段转化漏斗、停留时间、渠道、失败原因和下一步；
- 岗位族、公司类型、简历版本和证据覆盖对比；
- 面试问题与薄弱要求聚合；
- 将复盘结果生成待确认的资产改进任务。

## V2.0：目标公司公开情报

目标：为求职决策和面试反问提供有来源、有时效的公司研究，而不是私人背调。

范围：

- 公司基本信息、上市/融资、工商、投资、司法、知识产权；
- 招聘岗位、薪酬区间、办公地点、公司规模和阶段；
- 官网、公众号、公开社媒、新闻、会议、展会和学术成果；
- 招聘平台和公开评价的主观样本；
- 来源引用、采集时间、TTL、冲突信息和可信度；
- 公司研究 Skill 和可选混合检索/RAG；
- 与 JD 分析、风险清单和反向提问连接。

不建设 HR 私人画像，不推断领导人格和喜好，不把匿名评价当成确定事实。

## 版本成功指标

| 阶段 | 核心指标 |
|---|---|
| V1.7.3 | 过期分析、虚假 Mock、断链证据和恢复丢失相关回归为零 |
| V1.8.x | 关键话术的原子事实引用率、数字证据完整率、项目结构完成率 |
| V1.9.x | 用户答案修订完成率、资产复用率、话术证据覆盖提升 |
| V2.0 | 有来源结论比例、过期资料提示率、冲突信息显式呈现率 |

不把 ATS 分、面试率或 Offer 率单独作为产品成功指标，避免引导用户为了分数牺牲真实性。
