# 简历专家研究工作区

本目录用于保存“简历专家”产品与技术研究过程中的公开资料摘要、代码审计记录和最终研究报告。

- 不保存真实用户简历、API Key、Flowise 凭据或运行 Trace。
- 外部资料应记录来源、访问日期，并区分公开事实、用户自述和推断。
- `prd/` 仍保持用户现有未跟踪状态，不在研究工作中覆盖。
