# 目标公司公开研究模块规范

## 1. 模块定位

该模块的目标是帮助用户：

- 判断岗位和公司是否值得继续投入；
- 理解 JD 所处的业务背景；
- 发现需要面试验证的未知和风险；
- 准备有针对性的反向提问。

它不是私人调查工具，也不能保证公开数据完整、实时或准确。

## 2. 信息分区与来源优先级

| 分区 | 信息 | 优先来源 | 主要风险 |
|---|---|---|---|
| 企业身份 | 公司名称、统一主体、注册资本、成立时间、法定代表人、地址、股权 | 官方登记、交易所、监管披露 | 同名主体、历史变更、集团关系 |
| 资本状态 | 上市、融资轮次、金额、投资方、相关持股企业 | 交易所、监管披露、公司公告、投资方公告 | 未披露融资、媒体估值当事实 |
| 业务实力 | 产品、客户、市场、收入信号、合作、战略 | 官网、年报、公告、客户案例 | 营销表述与实际规模不一致 |
| 招聘与薪酬 | 在招岗位、地点、职级、薪酬、福利、工作时间 | 公司招聘页、招聘平台、岗位快照 | 岗位下线、区间样本偏差、口头承诺 |
| 知识产权 | 专利、商标、软著、学术成果 | 官方知识产权数据库、论文索引 | 名称映射和归属错误 |
| 司法与劳动 | 诉讼、执行、处罚、劳动争议 | 法院、监管、官方公开记录 | 案件阶段、同名主体、案由误读 |
| 新闻与动态 | 新闻、公众号、社媒、展会、会议、近期规划 | 公司官方渠道、主流媒体、会议官网 | 转述失真、计划未落地 |
| 主观体验 | 氛围、管理、加班、双休、年终奖、欠薪体验 | 招聘/职场评价、公开访谈、用户自述 | 匿名、极端样本、时间差、无法核验 |

每条结论至少显示来源链接、来源类型、发布日期/采集时间和主体匹配状态。

## 3. 事实、信号、推断和未知

统一使用四类标签：

- `已核实事实`：来自权威一手公开来源或用户明确确认；
- `公开信号`：招聘、新闻、展会、社媒等可观察变化；
- `系统推断`：从多个事实/信号推导，必须带依据和置信度；
- `未知/待验证`：没有足够来源，转化为面试或沟通问题。

主观评价额外标注 `主观样本`，不能因样本数量多就自动升级为事实。

## 4. 禁止与限制

### 不提供

- 非公开的个人住址、联系方式、家庭、财务或身份信息；
- 对 HR、领导、同事进行人格评分、心理画像或个人喜好推断；
- 根据姓名、照片、社交关系推断敏感属性；
- 对具体个人的“恶劣程度”自动评级；
- 未经来源支持的欠薪、违法、欺诈等确定性指控。

### 有条件提供

- 加班、双休、年终奖、分红、管理氛围：仅展示招聘承诺、公开制度或主观样本，注明时间和样本偏差；
- 劳动仲裁和诉讼：展示公开案件事实、案由、阶段、时间和主体，不代替法律判断；
- 公司实力总评：拆为若干有证据的维度，不输出一个假精确总分；
- 公司未来规划：区分官方公开计划与系统推断。

## 5. 研究任务流程

```text
输入公司名称 / JD / 地点
→ 主体消歧
→ 用户确认目标主体
→ 按来源类别采集
→ 去重、时间归一和冲突检测
→ 事实 / 信号 / 主观样本分层
→ 生成有依据的岗位影响分析
→ 生成未知项和反向提问
→ 用户保存研究快照
```

主体没有确认前不得合并工商、司法或新闻信息。

## 6. 时效与冲突

建议 TTL：

- 当前招聘岗位：7–14 天；
- 薪酬与工作方式：30 天；
- 新闻、社媒、展会：30 天；
- 融资、上市和重大工商变更：90 天；
- 基础工商身份：180 天；
- 主观体验：永久保存原发布日期，但不代表当前状态。

来源冲突时并列展示，不让模型静默选一个。用户可以标记“已通过面试/沟通确认”，但这仍属于用户自述来源。

## 7. 与简历主流程的连接

公司研究不直接写入简历。它只产生：

- JD Requirement 的补充业务背景；
- 系统推断及其来源；
- 风险清单；
- 反向提问；
- 用户求职偏好检查；
- 面试准备主题。

公司研究过期不会使个人事实过期，但会使相关岗位推断和反向提问进入 `stale`。

## 8. RAG 与数据连接器

该模块是最适合后续使用 RAG 的部分，但要先建立来源快照和主体消歧：

1. 连接器保存原始来源、访问时间和正文哈希；
2. 将长文切片并保留 source ID；
3. 检索结果返回引用片段和时间；
4. 模型生成的每条结论必须引用 source IDs；
5. 没有引用的结论只能成为待验证问题；
6. 删除或过期来源时，依赖结论自动过期。

向量相似度不能用于判断公司事实真假，也不能解决同名主体问题。
